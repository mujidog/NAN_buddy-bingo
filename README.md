# NAN_buddy-bingo
## 게임
90년대 영어 학습 프로그램처럼 생긴 5×5 빙고. 라운드가 올라갈수록 버디의 말투와 화면이 함께 망가지는 호러 빙고 게임.

| | 규칙 |
|---|---|
| 1라운드 | 기본 빙고. 틀린 칸은 타서 다시 못 누름 |
| 2라운드 | **20초 답변 제한.** 고민하는 동안 하트가 실시간으로 깎이고, 다 비면 한 칸 잃음 |
| 3라운드 | 두 줄 완성 시 보드가 뒤집힘. 도망 단어 5개가 `DIE`로 바뀌고, 누르면 전용 죽음 대사 |

엔딩은 둘(`영원히 놀자` / `찾았다`)이고 톱니바퀴 메뉴에서 수집 현황을 봅니다.
