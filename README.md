# NAN_buddy-bingo

90년대 영어 학습 프로그램처럼 생긴 빙고 게임. 다만 안에 있는 캐릭터가 살아 있다.

플레이어는 버디가 설명하는 뜻을 듣고 5×5 보드에서 맞는 영단어를 찾아 누른다.
가로·세로·대각선으로 세 줄을 만들면 다음 라운드로 넘어간다. 라운드가 올라갈수록
버디의 말투와 화면이 함께 망가진다.

## 라운드 구성

| | 분위기 | 규칙 |
|---|---|---|
| **1** | 밝은 숲, 상냥한 버디 | 기본 빙고. 틀린 칸은 타서 다시 못 누른다 |
| **2** | 해가 지고 존댓말이 사라진다 | **20초 답변 제한.** 고민하는 동안 하트가 실시간으로 깎이고, 다 비면 한 칸 잃는다 |
| **3** | 붉은 밤, 판정 프로그램 | 두 줄을 완성하면 보드가 뒤집힌다. `escape`·`run`·`hide`·`leave`·`forget` 칸이 `DIE`로 바뀌고, 누르면 그 단어 전용 죽음 대사와 함께 끝난다 |

## 엔딩

- **영원히 놀자** — 3라운드에서 세 줄을 완성한다
- **찾았다** — 도망 단어 칸을 누른다

어느 쪽이든 마지막 대사는 **타이핑 도중 끊긴다.** 하트와 타일 글자가 사라지고,
창 제목이 `BUDDY.EXE — 응답 없음`으로 바뀌고, 화면이 회색으로 얼어붙은 뒤
브라운관처럼 가로선 하나로 접히며 꺼진다. 그리고 바탕화면이 나온다.

수집한 엔딩은 톱니바퀴 메뉴에서 확인할 수 있다.

## 실행

```bash
npm install
npm run dev
```

| 명령 | 설명 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 타입 검사 + 프로덕션 빌드 |
| `npm test` | 단어 은행 불변식 검사 |
| `npm run lint` | oxlint |

개발 중에는 `Shift`+`1`/`2`/`3`으로 라운드 이동, `Shift`+`4`로 즉사,
`Shift`+`0`으로 창 닫기 연출을 볼 수 있다.

## 구조

```
src/
  game/
    BuddyGame.ts   상태 머신 전체 (React 밖)
    data.ts        단어·대사·엔딩 스크립트
    visuals.ts     공포도(dread)를 CSS로 바꾸는 selector
    save.ts        엔딩 수집·소리 설정 (localStorage)
  components/      화면별 렌더링
scripts/           에셋 추출·정리 도구
```

게임 로직은 React 밖 `BuddyGame` 클래스에 두고 `useSyncExternalStore`로 구독한다.
진행이 타이머 체인이라 이펙트로 흩는 것보다 한 객체에 모으는 쪽이 정확하다.
컴포넌트는 렌더만 한다.

화면은 1440×1080 고정 무대를 `ResizeObserver`로 측정해 축소한다. 창 크기와
무관하게 잘리지 않는다.

## 에셋

버디 스프라이트·배경·말풍선은 Claude Design 프로토타입의 번들 export에 base64로
들어 있던 것을 `scripts/extract-bundle.cjs`로 추출했다. 이 스크립트는 **이미 있는
파일을 덮어쓰지 않는다** — 손으로 교체한 스프라이트를 다시 뭉개지 않기 위해서다
(갱신하려면 `--force`).

- `scripts/import-sprite.py` — 새 스프라이트를 넣는다. 흰 배경 제거, 여백 크롭,
  500px 정규화, 귀 잘림 검사까지 한다
- `scripts/clean-sprite.py` — 구석에 붙은 얼룩을 떼어낸다

> 알려진 문제: `buddy_happy`·`buddy_worry`·`buddy_glitch`는 원본 아트에서 귀 끝이
> 잘려 있다. 온전한 원본으로 교체가 필요하다.
